# This is the stretch of completed fullstack integration assessment. It is now a finished assesment.

## This project originally included the following:
- A simple REST API using Express.js
- A React frontend that can make requests to the API
- A basic database (in this case, an array of products) to store and retrieve data
- Some middleware to log every request and allow CORS
- Simple UI components (React) to display the products and allow users to add, edit products
- An api test file for testing api using REST Client extension.
- .env file for frontend (Vite)

## Now, this project additionally includes:
- MongoDB as the backend database, fully functional and replaced in-memory array.
- Two .env files for frontend, backend (Vite and MongoDB)
- Search/sort functionality
- Request validation
- Product page when clicked on product
- Basic optimistic UI updates
